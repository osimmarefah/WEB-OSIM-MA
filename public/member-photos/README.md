# Member Photos
Avatar filenames must follow exact format for Structure page:

**Rules:**
1. Full name → lowercase
2. Spaces → '_'
3. Keep '-' (hyphen) as-is (e.g., al-mahmudi)
4. NO parentheses or extra text
5. For Koordinator: append '_koordinator' at end (NO "(Koordinator)" in filename)

**Examples:**
- Muhammad Nidzam Al-Mahmudi → `muhammad_nidzam_al-mahmudi.jpg`
- Achmad Fauzan Muttaqien (Koordinator) → `achmad_fauzan_muttaqien_koordinator.jpg`
- Anshor Dwi Darmawan (Koordinator) → `anshor_dwi_darmawan_koordinator.jpg`
- Ghitrif Syauqi Al-Afghany → `ghitrif_syauqi_al-afghany.jpg`

**Upload JPGs here.** Structure page auto-generates src from member names using `getAvatarSrc()`. Refresh /structure to see updates!
